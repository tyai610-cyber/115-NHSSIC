## GitHub Pages

解壓 ZIP，將 `index.html`、其他 HTML/JS/CSS、`assets/`、`data/`、`sixth/` 一併上傳到同一儲存庫 **根目錄**。GitHub Repository → Settings → Pages → Deploy from a branch → main → /(root)。

登入／註冊均不需要，全部資訊在前端讀取。本機 `file://` 的連結無法供其他裝置使用，公開分享請使用 GitHub Pages HTTPS 網址。
