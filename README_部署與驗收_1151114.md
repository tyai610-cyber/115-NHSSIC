## 本版範圍
- 以 115/11/14 最新更名版 ZIP 為基準，執行三輪「資訊正確性 → 手機操作與導覽 → 交通、來源與歷史文件」修正。

- 公開網站不提供 QR Code；仍可在個別日程與進階導覽頁複製職種專屬網址。

## 三輪重點
1. `agenda.html` 特殊報到卡僅於 11/24 出現，11/25–27 自動隱藏。
2. `ceremony.html`「典禮程序」分類納入 08:50 典禮開始、12:00 禮成，總清單仍為原始 22 項；典禮項目可用滑鼠、Enter、空白鍵標記。
3. 手機首頁優先顯示六個需求入口，原典禮詳細時間卡移到六入口後面；搜尋無結果顯示提示。
4. 行政大樓教室圖加入手機橫向滑動提示，選擇教室後可自動將選定區塊移入視窗，保留原教室格位。
5. `venues.html` → `sixth/index.html?venue=<場域代碼>#explorer`：直接載入指定場域，不再以該場域第一個職種作為深連結代替。
6. 官方交通頁明確標示只有「文字步驟輪播」，不是動態導航；第六輪任意兩點避樹仍為未核定技術示意。
7. 統一行政樓及個別日程的主要功能導覽；歷史 README 加註舊版性質、提醒 QR 已移除。

## GitHub Pages 部署
1. 解壓完整 ZIP，**所有檔案及資料夾**放在儲存庫根目錄，確認根目錄直接包含 `index.html`、`assets/`、`data/`、`sixth/`。
2. Commit / Push 至 `main`；儲存庫 Settings → Pages → Deploy from a branch → main → /(root) → Save。
3. 開放網頁後用手機確認：首頁六入口、職種搜尋、11/27 典禮、七張交通圖、場域進階連結、行政大樓教室、原版避樹試作及下載 PDF。
4. 正式公開前再人工確認地圖標點、臨時管制、使用授權及檔案中是否包含不宜公開的資訊。

- 靜態網站能在 GitHub Pages 上運作，但**本機瀏覽器測試不等於線上真實網址驗收**。
