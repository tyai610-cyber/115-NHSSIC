## GitHub Pages 部署
1. 解壓本 ZIP。將所有檔案和資料夾（包含 `assets/`、`data/`、`sixth/`）放在 GitHub 儲存庫的根目錄。**不要只上傳 ZIP。**
2. Repository → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save。
3. 網頁發佈後，逐一從六入口開啟內頁，檢查職種連動、三日行程、教室圖、交通及典禮。
4. 本版 QR Code 已全數移除，不需執行 QR 掃碼驗收。可測試普通職種網址 `individual.html?skill=14` 與 `sixth/index.html?program=14#explorer`。
