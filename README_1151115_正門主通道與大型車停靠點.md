## 官方資料及限制
- 115/11/12 大會手冊「交通接駁停車指引」圖一、二、五、六（第 130、131、134、135 頁）。
- 遊覽車及校車：萬壽路二段後門附近臨停、上下客後即駛離。
- 8 噸（含）以上工具車：萬壽路二段經後門後路邊臨時卸貨，不進校內迴轉。
- 原手冊另使用「8 噸以下」用語，剛好 8 噸的分類有文字交界，請依交通組核定及現場指示，不自行變更原規則。
- 避樹模組只依校園底圖和人工圖形遮罩繪製**示意線**，沒有校園步道/施工禁入區/車輛管制/無障礙路線的實測資料。不得據此導航駕駛或宣稱現場已開放通行。

- 官方交通總圖同時看到兩個高亮區；貨車圖只看到大型工具車區；遊覽車圖看到臨停區；切換停靠點快捷可到正確頁。
