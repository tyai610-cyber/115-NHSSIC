# 115 工科賽｜六個外場域「入口 → 競賽場館」動畫

## 已加入
- `venues.html` 新增六個外場域各職種的校門→場館路線示意，總計 10 個職種目的地。
- `skills.html` 在外場域職種新增「從校門到競賽場館動畫」快速連結。
- 地圖可切換箭頭／行人／只看路線，播放、暫停、重新播放；與原有縮放同步。
- 來源為 115.11.12 的六張原始校園圖；場館名稱參照現有 29 職種原始資料。

## 重要限制
- 這些**不是已核定的真實步行導航**，不得用於車輛導航。
- 新興高中及泰山高中原圖明確有指引線；南港高工部分人行指向可供參考；其他三場域主要只能確認校門及目的館舍，路段需由場地管理人員現場確認。
- 每筆路線的座標在 `venue-route-data.js` 的 `p` 清單，以 11/12 原圖裁切的縮小視圖標記；可依實測或校方修正。
- 萬能科大可能有兩個警衛室，本版以**萬能路／萬能橋側入口**為預設，不等於所有車種正門。桃竹苗分署以**秀才路警衛室**，南港高工以**興中路校門**，泰山高中以**辭修路側大門**，新興高中以圖上**校門口（東側）**，三重商工以**中正北路校門**。
- 29 機器手臂技術的學科在行政大樓 401；這次演示的是**術科活動中心**。萬能科大 15／18 示意到覺民館，樓層教室需要場館內指引。
