# 115 工科賽一站式資訊平台｜模糊搜尋整合更新（115/11/15）

## 本次功能
- 入口：首頁 `index.html`、職種查詢 `skills.html`、個別日程 `individual.html` 全部使用共用 `skill-search.js`。
- 支援：職種編號（含全形數字）、部分名稱、常見簡稱／別名、相差一個字的近似搜尋（避免兩字短查詢產生大量誤選）。
- 排序：正式名稱／編號完全符合 → 常見別名 → 名稱開頭 → 名稱包含 → 相近錯字；有明確結果時，不混入較不相關的錯字候選。
- 輸入立即查詢；首頁按 Enter 開啟最高吻合職種；個別日程使用搜尋建議、Enter、鍵盤上下方向鍵選職種。
- **不變更**：29 個職種的正式名稱、學術科時程、場館位置、導覽圖、QR Code 移除狀態及交通動畫。

## 測試用例
- `汽修` → `12 汽車修護`（不誤列 26 汽車噴漆）
- `冷氣` → `02 冷凍空調`
- `機器人手臂` → `29 機器手臂技術`（別名）
- `14`／`14車床` → `14 車床`
- `車` → 車床、汽車修護、汽車噴漆
- `機器手壁` → 29 機器手臂技術（近似錯字，顯示提示）
- `飛機修故` → 24 飛機修護（近似錯字）

## GitHub Pages
- 首次部署或版本不明：採用 **完整 GitHub 部署 ZIP**，解壓後上傳全部檔案至 Repo 根目錄，確保 `index.html` 位於根目錄。
- 若確定上一版為「115/11/15 考生教師三項體驗優化完整網站」：可使用 **更新覆蓋包**，保持資料夾層級，複製覆蓋對應檔案並新增 `skill-search.js`、`skill-search.css`。
- 不要直接把 ZIP 上傳當網頁，也不要只更新 HTML 卻漏掉新 JS/CSS。
- GitHub Pages 設為 `main` / `/(root)`，部署後確認跨頁及手機連線。
