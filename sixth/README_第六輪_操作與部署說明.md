# 115 工科賽｜第六輪：正式部署前整合版

## 使用
1. 進入網站，選取 01–29 職種；原有三日時間軸、7 場域導覽、首日及再次報到、分享 網址分享功能保持不變。
2. 北科附工 07、08、09、10、11、13、14、22、23 等學科場地選取後，顯示行政大樓 1F / 2F / 3F 教室原始圖面。
3. 在「行政大樓互動樓層與教室定位」切換樓層，點選框線可切換職種；手機可橫向滑動地圖。
4. 2F 動力一為 07 化驗；其餘 14 間在 3F。原始圖沒有精確教室門口或樓梯入口定位，因此**不提供路徑或走路距離**。
5. 職種獨立崗位配置圖只有在正式核定版匯入後才會顯示；目前 4 份較早來源已放入**本機維護包**，不在公開 ZIP。

## GitHub Pages 部署
解壓完整 GitHub ZIP，將 **內層** `index.html`、`.js`、`.css` 與 `assets/` 上傳至同一個儲存庫根目錄；至 Settings → Pages 選 Deploy from a branch → main → /(root)。

也可使用快速單檔版，只需上傳 `index.html`，但不含高解析原始圖；請勿連同維護包、Excel 來源、歷史配置圖一起公開上傳。

部署後逐一測試 29 個職種分享網址，例如 `https://您的帳號.github.io/您的儲存庫/?program=07#explorer`，並使用手機測試職種專屬網址。**此範例網址尚非真實公開網址。**
