# 115工科賽｜第五輪考生專屬導覽與三日行程

## 操作方式
- 選擇 01–29 職種，查看 115/11/24 首日報到時間、場地、11/24–26 時間軸。
- 時間軸可切換日期；另外標示每日再次報到、考試前點名與未公告時段。
- 點選「報到／學科／術科」可切換相對應場域導覽圖。行政大樓教室提供 1F／2F／3F 查詢，僅是樓層教室索引，不是精確室內座標。
- 【115/11/14 更新說明】第五輪曾規劃 QR；目前正式部署版本已移除 QR Code，只保留 29 職種圖面與職種專屬網址分享。

## GitHub Pages 上傳
- **最簡單**：將「快速部署版」壓縮檔解壓，將 `index.html` 上傳新建的 Public Repository 根目錄，Settings → Pages → Deploy from a branch → main → /(root)。
- **完整版**：解壓並上傳內含所有 .js、.css、assets 的公開網站資料夾**內部**檔案（index.html 必須在根目錄），同樣啟用 Pages。
- 本機維護工具與 Excel 來源檔不應放入公開網站。要修改正式資料需編輯程式/資料後重新上傳並部署。
