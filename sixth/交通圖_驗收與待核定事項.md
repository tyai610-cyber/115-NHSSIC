# 北科附工任意兩點動畫交通圖｜檢核紀錄

## 已完成程式驗證
- 38 個已列出的起終點選項，兩兩切換皆有回應，含同一建築的重複位置。
- 地圖可任意點選兩處並產生動畫線段。
- 「示意路網」採 Dijkstra 最短連線演算法；「兩點連線」顯示相對位置。
- 21／22／23 相關車輛入口不啟用未經核定的行車路網。
- 桌機 1440×900 與手機 390×844 模擬測試，沒有 JavaScript 例外或整頁水平溢出。
- 支援路線網址參數 from／to／mode；正式網址發布後仍需掃碼或跨裝置驗證。

## 仍未完成（需現場確認，不可視為核定）
1. 路網節點的實際可通行性、路口轉彎、坡道、樓梯及建築入口。
2. 21 大貨車後門、22 中小貨車、23 停車區的管制與允許行車區域。
3. 施工封閉區與特定競賽時段的動線管制。
4. 全部 38 個名義位置的精確出入口，而不只是建築物中心定位。
5. 其他六場域獨立路網與動態導引。
6. 校外任意 GPS 現址至各校校門的即時道路導航。
7. GitHub Pages 部署後的手機掃碼及不同裝置實測。

所有線段在 UI 上保持「示意路線，尚未核定」。
