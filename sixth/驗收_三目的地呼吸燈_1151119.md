# 115 工科賽｜報到、學科、術科呼吸燈資料及程式驗收紀錄

來源：GitHub 主站最新圖面資料 `sixth/data.js`（29 職種、7 場域、10 張導覽圖），報到圖 `map-01`、學科圖 `map-02`、術科圖 `map-03` 與六外場圖 `map-04`～`map-09`。圖面定位參考另列於 `destination-beacons.js`。

## 規則與重要限制

- **明確區分目的地**：報到為橘色「報」、學科為藍色「學」、術科為紅色「術」，使用固定中心點及兩層交錯擴散光圈。
- **並非實地測繪座標**：新資料只用既有原圖可核對的標號、科館與教室格位，以人工目視對應圖面百分比。藍色會議編號與報到桌不同時，僅表示同科館圖面參考區。行政大樓學科標記是原圖教室配置格位，**不是教室門口**。
- **外場僅館舍層級**：報到與學科沿用各外場原已存在的職種館舍圖面參考標記，**不得理解為報到桌或學科教室的精確位置**；實際使用須核對現場公告。
- **術科座標保留**：原始 `sixth/data.js`、`sixth/focus-meta.js` 均未變動。
- **圖面裁切**：選取的學科參考點超出重點圖時自動切換完整圖面，避免光圈不可見。
- **圖例／高亮效果**：新 CSS 提供雙層呼吸燈及減少動態的靜態高亮，保留原有點位群組與操作功能。
