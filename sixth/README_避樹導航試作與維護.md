# 115 工科賽｜北科附工任意兩點動態導航：樹木避讓版 v0.3

## 使用方法
1. 最簡單：下載「單檔 HTML」，直接用 Chrome 或 Edge 開啟；可離線使用。
2. 起點與終點可由 38 個圖面位置中選擇，也可按「點圖選起點／終點」指定任意非避讓區位置。
3. 模式「避樹優先」使用 5 座標單位避讓緩衝；「加大避讓」使用 12 座標單位。兩種模式均禁止穿越遮罩。
4. 植栽區在地圖上以紅色斜線區域顯示；可隱藏圖層，但路線仍會避讓。
5. 「播放／暫停」、「交換起終點」、「縮放」、「複製專屬路線」可正常使用。

## 避讓區（根據上傳的北科附工示意圖人工標註）
- 維也納森林西側樹木區（矩形）。
- 維也納森林東側樹木區（矩形）。
- 行政大樓前圓環中心花圃（橢圓）。
- 苗木果樹區（矩形）。

程式資料在 `traffic-data.js` 的 `obstacles` 陣列，可改成實際勘察結果。坐標採地圖 `viewBox: 1000 x 667`，不是 GPS 坐標；調整區塊或換地圖後應重新驗證。建議先經承辦與現場管理確認再公開。

## 演算法
- 先以樹木遮罩加緩衝距離建立禁止穿越格網。
- 使用 A* 最短路徑搜尋（含斜向禁止切角）。
- 路徑平滑後，再逐段採樣確認不穿越樹木遮罩。
- 起終點選在避讓區內時拒絕選點，不畫穿越樹木的捷徑。
- 全部連線皆是「圖面避樹示意」，不能代替真正的步道、建物出入口、車道、圍牆、坡道及施工管制驗證。

## 驗證範圍
2026-11-13：Chromium 1440×900、390×844 測試；38×38 = 1,444 組預設點位，在避樹優先及加大避讓模式均成功避開四處目前的遮罩。另隨機抽驗 198 組有效自選座標，無樹木遮罩碰撞。這是程式幾何檢查，不是現場通行驗收。
