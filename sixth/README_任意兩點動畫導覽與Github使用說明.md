# 115 工科賽｜北科附工任意兩點動態導航（試作 v0.2）

## 本次相對於上一版的改變

原來只支援 3 條指定步行路線及 3 個車輛入口。新版改成 **任選起點 → 任選終點** 的方式，不再依賴固定路線組合。

- 下拉選擇 38 個校園館舍、服務點、入口及設施（部分共享相同建築座標）。
- 在地圖任意點選起點與終點，兩次點選後即更新路線；目前不支援取得現實 GPS 定位。
- 使用節點圖與最短路徑演算法產生動畫示意折線，亦可切換「兩點連線」（表示方位，不是道路）。
- 支援交換起終點、播放暫停、放大縮小、顯示路網節點、分享選擇的起終點 URL。
- 校園圖、原有服務定位點保留；沒有變更原始建築圖位置。

## 重要安全標示

**本版仍是動畫技術測試，不是核定的步行或行車導航。**

- 示意節點與其連接關係由視覺設計建立，未依實際行人通道逐段查核；動畫可能穿越植栽、建築及不開放區域。
- 編號 21 大貨車、22 中小貨車、23 停車入口相關起終點，系統自動限制為兩點位置連線，**不會計算未核定的車行路徑**。
- 若兩個選項位於同一張圖的相同座標（如行政大樓不同樓層），會顯示「同位置無需校園步行動畫」，應另看樓層導覽。
- 路線視覺長度 **不是實測距離**，亦不提供時間／行車可通行判斷。
- 目前僅涵蓋 **北科附工校園底圖**；另外六個場域要分別確認校園路網後才能套用。
- 若要導航「校外目前 GPS 位置 → 校門」，需 GPS 授權及外部道路圖服務；此版本不提供。

## 立即試用

下載「115工科賽_北科附工_任意起終點_動態導航_單檔試用.html」並用 Chrome / Edge 開啟。可離線使用。

1. 從「起點」與「終點」的下拉選單選擇任兩處。
2. 或按「點圖選起點」，在地圖點一次，再點第二次指定終點；允許自由座標。
3. 選擇「示意路網」或「兩點連線」。
4. 可交換起終點、播放／暫停動畫、縮放與顯示節點。
5. 發布網站後，點「複製專屬路線」可將選擇的兩處及模式記錄在網址參數。

## GitHub Pages 部署

### 單檔版本

將單檔試用版改名為 `index.html`，放到新建立的 GitHub 儲存庫根目錄。Settings → Pages → Deploy from a branch → `main` → `/(root)`。注意這是**單獨的交通導覽**，不含原先七場域主網站。

### 整合既有第六輪網站

使用本次提供的「第六輪＋任意兩點動畫整合版.zip」：將解壓的所有檔案放入 GitHub 儲存庫根目錄，不要直接上傳 ZIP。首頁 `index.html` 仍是七場域網站；由導覽列進入 `traffic.html`。如果只是更新既有第六輪網站，也能用模組 ZIP 中的 `traffic.html`、`traffic.css`、`traffic-data.js`、`traffic.js`、`assets/campus.webp` 覆蓋原交通模組。

路線網址範例（部署後）：`https://帳號.github.io/儲存庫/traffic.html?from=gate&to=third&mode=walk`

**尚未正式部署時**，本機的 `file://...` 網址只能在原電腦使用，不代表其他人能打開。

## 正式導引上線前需要做的事

- 請總務／交通引導／場地組逐段確認：可通行走道、樓梯出入口、障礙、施工區、人車分流、車輛尺寸、開放時間。
- 在 `traffic-data.js` 修改 `nodes`（路網節點）、`edges`（允許連線）及 `locations`（館舍服務點）。**注意：這些現在都是示意連線，沒有任何一條因程式能動畫就代表核定。**
- 設置單獨的路線核定狀態、日期、審核人員，再決定哪些可以在公開網站顯示為實際行走路線。
- 交通模式需有自己的核准道路網，不可直接套用行人路網。
- 請用不同手機與實際現場通行測試完成驗收。

## 測試範圍

在本機 HTML 頁面模型中以 Chromium 驗證了 38 個選擇位置、點圖自由選點、下拉切換、交換起終點、放大縮小、暫停及分享參數的邏輯。對於不同名稱卻共享同一個圖面座標的選項，程式提示「同位置」而不畫假的移動路線。
