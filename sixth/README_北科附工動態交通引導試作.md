# 115 工科賽｜北科附工動態交通引導試作 v0.1

日期：115/11/12。**這份程式是技術及操作試作，不是交通公告，所有動態線條都尚未經現場核定。**

## 立即試用

直接開啟 `115工科賽_北科附工動態交通引導_單檔試作.html`，不用網路、伺服器或 Python。

可操作功能：考生、領隊／教師、大貨車、中小貨車、小客車身分切換；步行流動虛線及方向箭頭；車輛入口定位；路線選單；暫停播放；地圖縮放、滑動；複製含 `?route=` 的示意網址；原始地圖局部下載。手機可直接操作。

## 資料來源

沿用第六輪版北科附工大會服務校園導覽圖，保留 21 萬壽路側後門、22 成功路側校門，以及第三會議室、行政大樓、耕讀樓之相對位置。

路徑轉折點 `traffic-data.js` 中的 `points` **只是為測試動畫呈現而安排的示意座標**，沒有實測，不表示任何通道已可通行。**車輛模式僅標示入口方位，絕無校內行車路線。**

## 套用至第六輪網站

這包提供 `traffic.html`、`traffic.css`、`traffic.js`、`traffic-data.js`、`assets/campus.webp`。將這些檔案依原資料夾路徑放到第六輪 GitHub 儲存庫，並在原網站首頁導覽列加入：

```html
<a href="traffic.html">交通引導（試作）</a>
```

完整整合候選版已包含這個連結，原有七場域、29 職種、時間軸、行政大樓樓層圖均保持原樣。

### GitHub Pages

將完整整合候選版 ZIP **解壓縮後的內容**上傳至 Repository 根目錄，不是直接上傳 ZIP。`index.html` 和 `traffic.html` 均位在根目錄；到 Settings → Pages 選擇 main/(root) 發布。

**正式對外發布前，務必先關閉此試作頁入口或明確保留未核定警告；不可使用示意轉折點作為正式路線。**

## 完成正式版本所需核對

1. 11/24–26 各校門／後門的開放、交通管制及時段。
2. 校門至第三會議室、行政大樓、耕讀樓的實際安全步行通道，含施工及禁止通行區。
3. 大貨車 21（8噸以上）實際路側裝卸位置、等候點、後門限制及核准方式。
4. 中小貨車 22（8噸以下）實際卸貨點及校內折返管制。
5. 小客車 23 停車場位置、停車證、出入口及校內動線。
6. 經負責人書面確認後，依現勘圖替換 `traffic-data.js` 中各路線 `points`，設定核定版本與公告日期，再開啟正式路線。
