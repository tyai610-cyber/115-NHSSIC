# 115 工科賽｜第六輪網站 × 任意兩點避樹動態交通整合版

## 本版整合內容（115/11/13）

這是以「第六輪網站＋動態交通引導整合候選版」作為基底，替換最新「北科附工任意兩點避開樹木」交通模組後的**完整 GitHub Pages 多檔部署版**。

- 首頁 `index.html`：7 場域、29 職種、11/24–26 三日行程、報到時間、行政大樓 15 間教室互動樓層圖、職種分享網址及 網址分享功能（依原有設計保留）。
- 交通頁 `traffic.html`：38 個預設位置互選，或在圖上自訂起終點；可交換、縮放、播放／暫停、分享示意路線。
- 避樹路線：依四處**人工標註的樹木及花圃遮罩**進行示意避障；有「避樹優先」及「加大避讓」兩種模式。
- 首頁導覽列已加入「避樹動態交通（試作）」；交通頁右上角可返回七場域導覽。

## GitHub Pages 部署

1. 將 ZIP **解壓縮**；請上傳解壓後的所有檔案與 `assets` 資料夾至 GitHub Repository 根目錄。不可只上傳 ZIP，也不可只上傳 `index.html`。
2. 開啟 Repository → `Settings` → `Pages`。
3. Source 選擇 `Deploy from a branch`，Branch `main`，Folder `/(root)`，按 Save。
4. 網站發布後，`https://<帳號>.github.io/<儲存庫>/` 為首頁；`https://<帳號>.github.io/<儲存庫>/traffic.html` 為交通頁。
5. 使用電腦與手機各測試首頁進入交通頁、返回首頁、38 個點位、地圖選點、動畫、樹木避讓及職種分享網址。

## 重要限制

**本版路線不是經現場確認的步行或行車指引，不應作為正式交通公告。** 已避開設定遮罩，不代表不穿越建築物、圍牆、封閉區或無法通行道路。21、22、23 的卸貨、車輛與停車位置及管制仍待核定。若要正式導引，須先由場地與交通負責人核定人行路網、各館出入口及封閉區域。

首頁原有的 29 職種資料、未核定定位與日程疑義都保留，沒有因本次整合改動。
