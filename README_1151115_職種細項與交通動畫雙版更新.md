## GitHub Pages 完整部署

1. 解壓縮「完整GitHub部署版.zip」，將 `index.html`、`sixth/`、`data/`、`assets/` 及全部相鄰檔案放在儲存庫根目錄（不要只上傳 ZIP）。
2. GitHub `Settings → Pages → Deploy from a branch → main → /(root)`。
3. 檢查 `individual.html`、`sixth/index.html`（三日時間軸）、`transport.html`（官方交通）及 `sixth/traffic.html`（避樹動畫）。
4. 已有舊站者可使用更新覆蓋包；應保留原始資料夾結構，不要將所有 JS 放在根目錄。
5. 若網站已部署，透過 GitHub Desktop Commit → Push 後，頁面會沿用原公開網址。
