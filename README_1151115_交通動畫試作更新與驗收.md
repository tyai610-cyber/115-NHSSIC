# 115 工科賽一站式資訊平台｜交通情境動態示意（115/11/15）

## 功能變動
- 更新 `transport.html`：官方交通七圖上方加入「移動箭頭／黑色行人／關閉」和「播放／暫停」選擇。
- 更新 `event-app.js`：依七圖情境切換 SVG 路徑上的移動標記，圖二至圖五以車行箭頭示意，圖六與圖七以黑色行人剪影示意；圖一為停車位置總覽，沒有單一路線，不強行播放動線。
- 更新 `event-design.css`：動畫 SVG 與地圖圖片同層同比例縮放；手機上能左右滑動查看，高解析不模糊；停用動畫時原圖保留。
- 動畫使用 HTML/SVG 原生動態（視覺效果如 GIF），並不需要實際載入 GIF，因而可與地圖縮放同步，也可立即暫停。
- 更新時不碰原第六輪任意兩點避樹試作 `sixth/traffic.html`，也不變動七張官方交通圖、所有職種資料及典禮時間。

## 操作
1. 進入網站「開車／停車」或「遊覽車／步行」後，選圖二～圖七。
2. 車行圖預設「移動箭頭」，人行圖預設「黑色行人」；後者也可切換「移動箭頭」。
3. 點「暫停動畫／播放動畫」控制地圖標記，與右側獨立的「文字步驟輪播」無關。
4. 「關閉」會隱藏動畫，留下原始大會手冊的圖面和路線；可隨時重新開啟。
5. 圖一為位置總覽不提供單一路線動畫；若使用者系統設定減少動態，預設停止播放。

## 導覽安全與範圍
- **重要：動畫僅標示原始圖已繪製之代表性方向區段，不保證完整車行或步行路徑。** 手工擬合的圖示軌跡只是幫助視覺辨認，與官方手冊圖上的箭頭有細微定位誤差。
- 七張來源地圖本體完全保留不改；若動畫與原圖局部不一致，以原始圖示為準。
- 交通規定、卸貨方式、通道及停車範圍請以 115.11.12 大會手冊及現場工作人員指揮為準，舊版 8 噸文字交界問題尚需交通組核定。
- 動態不自動補出新路段，不提供導航時間、距離、導航指令或車輛定位。
